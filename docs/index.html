ClipForge

Capture runs in the background. Press F8 to save the last 15–120 seconds, then trim, reframe and export. All local: no account, no cloud.

What it does

Replay buffer

Always-on capture of your display with a rolling 15–120 s buffer on disk. Hardware encoding (AMD, NVIDIA, Intel) with automatic fallback.

Global hotkey

Save a clip from inside your game with a configurable hotkey. Keeps recording from the tray when the window is closed.

Separate audio tracks

Desktop audio and microphone are recorded as separate tracks, so you can balance or mute them later.

Library

Thumbnails, search, sort, favorites and tags. Clips are plain MP4 files in your Videos folder.

Editor

Trim, split and cut sections, with undo. Reframe to 16:9, 9:16 or 1:1 with zoom and pan, and add text overlays.

Export

Frame-accurate H.264/AAC MP4 at original, 1080p or 720p, with progress and cancel.

Install

  1. Install the .NET 10 Runtime (needed for audio capture).
  2. Install FFmpeg so it's on your PATH. The easiest way is Scoop: scoop install ffmpeg. ClipForge doesn't include it.
  3. Download the zip from the latest release and extract it anywhere.
  4. Run ClipForge\ClipForge.exe. The app is unsigned, so Windows may warn the first time: click More info → Run anyway.
  5. Press Start capture, play, and press F8 to save.

Good to know

  • Captures whole displays, not single windows. Borderless and windowed games work; exclusive fullscreen hasn't been tested and may record black frames.
  • Saved clips can be up to 2 s longer than the chosen length, because they're cut on segment boundaries without re-encoding.
  • ClipForge never deletes your clips on its own. It only cleans up its own temporary files.
ClipForge is built with Electron and React, and uses your own copy of FFmpeg, which is licensed separately.
